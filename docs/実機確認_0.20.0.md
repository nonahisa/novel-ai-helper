## ① 保存したあと、どのアドレスへ移るか

**開く**：カクヨムの、どれか1作品の「新しいエピソード」の画面
**する**：題に「テスト」、本文に「テスト」と入れて［下書き保存］を1回だけ押す（あとで消してください）
**見る**：移った先のアドレス欄

答え：
1. `kakuyomu.jp/my/works/（数字）/episodes/（数字）` の形
2. 作品の管理画面（`/my/works/（数字）` だけ）に戻った
3. その他（アドレスを書いてください。数字は伏せて構いません）

アルファポリス・なろうでも同じことができれば、同じ答え方で（アルファポリスは `save_episode/（数字）/（数字）`、なろうは `noveldataid/（数字）` が出るか）。

## ② カクヨムの話の編集画面の題と本文の欄

**開く**：①で作った下書き（または既にある話）の編集画面
**見る**：題の欄・本文の欄が、新しいエピソードの画面と同じ並びか

答え：
1. 新しいエピソードの画面と同じ（題が上、本文が下の大きな欄）
2. 違う（どう違うか一言）

※欄の名前（id）は、こちらで読みます。画面を開いたまま「開いた」と言ってもらえれば、Claude が読みに行きます

## ③ アルファポリスの話の編集画面の章の欄

**開く**：アルファポリスで、既にある話の編集画面（`save_episode/（数字）/（数字）`）
**見る**：章を選ぶ欄があるか・その話の章が最初から選ばれているか

答え：
1. 章の欄があり、その話の章が選ばれている
2. 章の欄はあるが「選択しない」などになっている
3. 章の欄が無い

## ④ カクヨムの作品管理の話の行から、編集画面へ行けるか

**開く**：カクヨムの作品管理の画面（話が並ぶ一覧）
**する**：どれか1話の題を押す
**見る**：移った先

答え：
1. その話の編集画面へ移った（アドレスが ①-1 と同じ形）
2. 読者として見るページ（`/works/…`、`/my/` が無い）へ移った
3. その他

## ⑤ 編集画面の題の欄に、保存した題が入っているか

**開く**：②の編集画面（カクヨム）と、③の編集画面（アルファポリス）
**見る**：題の欄に、その話の題が最初から入っているか

答え：
1. どちらも入っている
2. カクヨムだけ入っている
3. アルファポリスだけ入っている
4. どちらも空
