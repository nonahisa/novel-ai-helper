## ① カクヨムで下書きを保存したあと、どのアドレスへ移るか

1. パソコンの Chrome で、新しいタブを開く
2. 上のアドレス欄に `kakuyomu.jp/my` と打って Enter（カクヨムの、ご自分の作品の一覧が出ます）
3. 一覧から、どれか1つの作品の名前を押す（その作品の管理画面が出ます）
4. その画面で、新しい話（エピソード）を書くボタンを押す
5. 題の欄に「テスト」、本文の欄に「テスト」と打つ
6. 画面の［下書き保存］を1回だけ押す
7. 移った先の、上のアドレス欄の字を見る

答え：
1. `kakuyomu.jp/my/works/（数字）/episodes/（数字）` の形
2. `kakuyomu.jp/my/works/（数字）` だけ（作品の管理画面に戻った）
3. その他（アドレスを書いてください。数字は伏せて構いません）

この「テスト」の下書きは、⑤まで見終わったら消してください（消し方はこの紙のいちばん下に書いてあります）。

## ② カクヨムの話の編集画面の題と本文の欄

1. パソコンの Chrome で、新しいタブを開く
2. 上のアドレス欄に `kakuyomu.jp/my` と打って Enter
3. 一覧から、どれか1つの作品の名前を押す
4. 並んでいる話のうち、どれか1つの題を押す（①で作った「テスト」でも構いません）
5. 開いた画面で、題の欄と本文の欄の並びを見る

答え：
1. 新しい話を書くときの画面と同じ（題の欄が上、本文の大きな欄が下）
2. 違う（どう違うか一言）
3. 手順4で、編集の画面ではなく、読者として読むページが開いた

※欄の名前（id）は、Claude が読みます。この画面を開いたまま「②を開いた」と送ってもらえれば、Claude が Chrome の拡張「Claude in Chrome」で読みに行きます

## ③ アルファポリスの話の編集画面の章の欄

1. パソコンの Chrome で、新しいタブを開く
2. 上のアドレス欄に `www.alphapolis.co.jp/mypage/content` と打って Enter（アルファポリスの、ご自分の作品の一覧が出ます）
3. 一覧から、章のある作品の名前を押す
4. 並んでいる話のうち、どれか1つの話の、編集のボタンを押す
5. 上のアドレス欄が `www.alphapolis.co.jp/mypage/novel/save_episode/（数字）/（数字）` の形になっているかを見る
6. その画面で、章を選ぶ欄と、そこに出ている字を見る

答え：
1. 章を選ぶ欄があり、その話の章が出ている
2. 章を選ぶ欄はあるが「選択しない」などが出ている
3. 章を選ぶ欄が無い
4. 手順5のアドレスの形にならなかった（アドレスを書いてください。数字は伏せて構いません）
