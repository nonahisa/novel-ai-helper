## 第1部　Chrome だけで済むもの

### A　説明のページの「1作品」は、どの欄だったか（2章13）

前に、説明のページで覚えた作品を外したあと「1作品」になったのを見ていただきました。それがどの欄だったかを教えてください。

1. パソコンの Chrome で、この拡張のアイコンを**右クリック**する
2. 出てきた一覧から「集計を表示」を押す（説明のページが新しいタブで開きます）
3. ページの中の、溜まりの欄（「いま N画面ぶん（M作品…）」のような字がある所）と、集計の表（作品ごとの見出しと数の表）を見比べる

答え：
1. 「1作品」と出ていたのは、集計の表のほう（作品ごとの見出しが1つになった）
2. 「1作品」と出ていたのは、溜まりの欄のほう（「いま N画面ぶん（1作品…）」）
3. 覚えていない

※1 なら決まりどおりです（外した作品の集計の記録は、わざと消す作り）。2 なら直すべき不具合です。

### B　暗いテーマのツールバーで、アイコンの絵が見えるか（0.12.2）

1. パソコンの Chrome の右上の「︙」（縦に点が3つ）を押す
2. 「設定」を押す
3. 左の一覧の「外観」を押す
4. 「モード」を「ダーク」にする
5. Chrome の右上の、この拡張のアイコンを見る（印「読」「貼」などが付いていれば、それも）
6. 見終わったら、同じ手順4で「モード」を元に戻す（「デバイス」か「ライト」）

答え：
1. 絵も印も見える
2. 絵が見えにくい（背景に溶ける）
3. 印が読めない

### C　ふつうのお知らせが画面の隅に出るか（0.8.0）

**この拡張のアイコンに数字（「読3」など）が出ているときは、この項目は飛ばしてください**（押すと読者の反応を渡して VS Code が前に出るため）。

1. パソコンの Chrome で、新しいタブを開く（何も打たない）
2. その空のタブのまま、この拡張のアイコンを押す
3. 画面の右下の隅に、この拡張のお知らせ（「ここでは…」のような文。字は確かめていない）が出るかを見る
4. 出なければ、Windows の画面の右下の時計を押して、通知の一覧に入っているかを見る

答え：
1. 画面の隅に出た
2. 隅には出ず、時計を押した通知の一覧にだけあった
3. どちらにも無かった

### D　新しく入れたときの、吹き出しと「はじめに」（0.10.0・0.14.0）

Chrome にもう1人ぶんの「プロフィール」を作って、拡張を入れたての状態を見ます。いつもの Chrome の中身には触りません。

1. パソコンの Chrome の右上の、丸い人の形（または頭文字）のボタンを押す
2. 「追加」を押す（確かめていない。「別のプロフィールを追加」のような名前のこともあります）
3. 「アカウントなしで続行」を押し、名前は「テスト」などで作る（新しい Chrome の窓が開きます）
4. 新しい窓のアドレス欄に `chromewebstore.google.com/detail/mbchfkieflpplhgaaefbdgjcbhkocbmc` と打って Enter
5. 「Chrome に追加」を押し、出てきた確認で「拡張機能を追加」を押す
6. 自動で開いた説明のページの先頭に「はじめに」の3つの手順が出ているか、統合小説執筆環境を知らない人が読んでも迷わないかを見る
7. 同じ窓で、アドレス欄に `kakuyomu.jp/my` と打って Enter し、カクヨムにログインする（ログインはご自分で）
8. 一覧から、どれか1つの作品の名前を押す（作品の管理画面が出ます）
9. 少し待ち、この拡張のアイコンから吹き出しが出て「開いたときに自動で取得しますか？」とボタンが2つ出るかを見る
10. 「自動で取得する」を押し、少しして「取得しました」が出るかを見る
11. そのあと、この拡張のアイコンを押して、吹き出しが出っぱなしにならないかを見る（新しく入れた拡張は「統合小説執筆環境へ渡す」が切ってあるので、説明のページ〔集計〕が新しいタブで開けば正しい姿です）
12. 見終わったら、手順1のボタンから「テスト」のプロフィールを選び、その窓の右上の歯車（確かめていない）からプロフィールを削除してよい

答え（手順6）：
1. 「はじめに」が先頭にあり、迷わず読めた
2. 「はじめに」はあったが、分かりにくい所があった（どこか一言）
3. 「はじめに」が無かった

答え（手順9〜11）：
1. 吹き出しが出て、「取得しました」も出て、押しても吹き出しは残らなかった
2. 吹き出しは出ず、画面の隅にボタン付きのお知らせが出た
3. 何も出なかった
4. 押したあと吹き出しが出っぱなしになった

### E　ランキングの画面のお祝い（0.19.0）

**ご自分の作品がいま載っているランキングが分かるときだけ**行ってください。

1. パソコンの Chrome で、新しいタブを開く
2. アドレス欄に `kakuyomu.jp/rankings` と打って Enter（カクヨムのランキングが出ます）
3. ご自分の作品が載っているジャンルと期間（日間・週間など）を選ぶ
4. 「カクヨムのランキングを開いたとき、自動で取得しますか？」と訊かれたら「自動で取得する」を押す
5. 吹き出しに「〈作品名〉が〈見出し〉で N 位に入っています。おめでとうございます！」と、風船か花火が出るかを見る
6. 同じタブで F5 を押して開き直し、お祝いが二度は出ないかを見る

答え：
1. お祝いと風船・花火が出て、開き直しでは出なかった
2. お祝いは出たが、風船・花火が見えなかった
3. 載っているのに「載っていませんでした」と出た
4. 何も出なかった

## 第2部　VS Code（統合小説執筆環境）も一緒に見るもの

この部は、VS Code で統合小説執筆環境を開いた状態で行います。どれも、Chrome で押すと VS Code が前に出ます。

### F　カクヨムのアクセス数の「次へ」のお知らせ（0.2.2）

1. パソコンの Chrome で、新しいタブを開く
2. アドレス欄に `kakuyomu.jp/my` と打って Enter
3. 一覧から、話が51話以上ある作品の名前を押す
4. 作品の管理画面で「アクセス数」（確かめていない）を押す
5. この拡張のアイコンを押す
6. 画面の隅（または時計を押した通知の一覧）に、次のページもある、という旨のお知らせが出るかを見る
7. VS Code で、その作品の読者の反応の記録に、1〜50話の数が入ったかを見る

答え：
1. 「次へ」の旨のお知らせが出て、VS Code に50話ぶん入った
2. お知らせは出なかったが、VS Code には入った
3. VS Code に入らなかった

### G　章立てを右クリックで渡す（0.13.0）

1. パソコンの Chrome で、新しいタブを開く
2. アドレス欄に `kakuyomu.jp/my` と打って Enter
3. 一覧から、どれか1つの作品の名前を押す（作品の管理画面が出ます）
4. ページの何も無い所で**右クリック**し、出てきた一覧の「統合小説執筆環境ヘルパー ›」に矢印を合わせ、横に出た「章立てを取得」を押す
5. 「大見出し N個と M話 の並びを…」のお知らせが出るか、VS Code が前に出て章立ての確認が出るかを見る

答え：
1. お知らせが出て、VS Code が前に出て、章立ての確認が出た
2. お知らせは出たが、VS Code が前に出なかった
3. 右クリックの一覧に「章立てを取得」が無かった

### H　「渡す」を切ったとき、Chrome が VS Code を開くか尋ねないか（0.11.0）

拡張の中の動きは機械で確かめました（2026-11-06）。残っているのは、本物の Chrome が尋ねないかだけです。

1. パソコンの Chrome で、この拡張のアイコンを**右クリック**し、「集計を表示」を押す
2. 説明のページで「統合小説執筆環境へ渡す」のチェックを外す
3. 新しいタブを開き、アドレス欄に `kakuyomu.jp/my` と打って Enter し、どれか1つの作品の名前を押す
4. この拡張のアイコンを押す
5. 説明のページ（集計）が開くか、Chrome が「Visual Studio Code を開きますか？」と尋ねないかを見る
6. 見終わったら、手順1・2で「統合小説執筆環境へ渡す」のチェックを入れ直す

答え：
1. 集計が開き、尋ねられなかった
2. 「Visual Studio Code を開きますか？」と尋ねられた

### I　なろうファンDB の取り込みの中身と日ごとのグラフ（0.7.0）

1. パソコンの Chrome で、新しいタブを開く
2. アドレス欄に `db.narou.fun/novels/` に続けて、ご自分の作品のNコード（小文字。例 `n2600go`）を打って Enter
3. この拡張のアイコンを押し、VS Code が前に出たら取り込みの確認で取り込む
4. VS Code の、その作品の読者の反応のグラフに「日ごとのブックマークの増減」が出て、減った日が0の線より下に赤で出るかを見る
5. 同じページで、もう一度アイコンを押して取り込み、VS Code の記録の件数が増えないかを見る

答え：
1. グラフが出て、減った日は赤で下に出た。2度目で記録は増えなかった
2. グラフは出たが、減った日が赤で下に出なかった
3. 2度目で記録が増えた
