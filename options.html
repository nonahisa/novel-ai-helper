統合小説執筆環境ヘルパー

ご自分の作品の読者の反応（PV・ブックマーク・評価など）を、管理画面を開いたときに記録し、 作品ごとにいまの数・日ごとの推移・離脱率などの率をこのページで簡単に集計します。 VS Code の拡張機能「統合小説執筆環境」をお使いの方は、原稿を投稿画面の欄へ入れたり、 読者の反応をまとめて渡したりにも使えます。

はじめに（3つの手順）

  1. ご自分の作品の管理画面を開く。 カクヨムなら、ログインして「作品の管理」から作品を選んだ画面（kakuyomu.jp/my/works/…）。 小説家になろうの作品なら、分析サイト Narou.fun の作品のページ（db.narou.fun/works/Nコード）です。
  2. 作品を覚える。 カクヨムの作品管理の画面は、ご本人しか開けないので、開いただけで自動で覚えます。 Narou.fun のページ（どなたの作品でも開けます）では、ツールバーのアイコンに ? が付きます。 アイコンを押して「覚える」を選ぶか、下の「ご自分の作品として覚えた作品」に Nコードを書いて保存してください。 覚えた作品だけを記録します（ほかの方の作品は記録しません）。
  3. 集計を見る。 覚えた作品の画面を開くたびに、その日の数を記録します。集計はこのページの下の「読者の反応の集計」で見られます。 あとから開くときは、ツールバーのアイコンを右クリックして「読者の反応の集計を見る」を選びます。

アイコンが見当たらないときは、ツールバーのパズルのかけらの印から「統合小説執筆環境ヘルパー」を固定してください。 入れた直後は、開いていた管理画面を一度読み直してください（この拡張は、ページを開いたときに入ります）。

読者の反応の集計

覚えた作品ごとに、いまの数・日ごとの数・率を出します。数は、画面を開いたときにサイトが出していた数そのままです。 率が出せないときは、0% とせずに、足りない材料を書きます。 

読み込んでいます…

記録は、同じ作品・同じ日の分を1つにまとめ、新しい数で置き換えます。残すのは で、越えたら古いものから消えます。 記録はこの拡張の中（Chrome の拡張用の保存場所）にだけあり、どこへも送りません。

もっと詳しく分析するには

グラフ・作品の事情を踏まえたAIの助言・原稿との突き合わせなど、詳しい分析は VS Code の拡張機能「統合小説執筆環境」でできます。この拡張で記録した読者の反応を、そのまま渡せます。

統合小説執筆環境（Visual Studio Marketplace のページ）

ご自分の作品として覚えた作品

この作品の画面を開いたときだけ、読者の反応を記録します。1行に1つずつ書きます。消した行の作品は、以後記録せず、 その作品の集計の記録も消えます。カクヨムの作品は、作品管理の画面を開くと自動で覚えます。

アイコンの印と、押したときにすること

ツールバーのアイコンを押すか、ページの上で右クリックして「統合小説執筆環境ヘルパー：…」を選ぶと、 いま開いている画面でできることを1つだけ実行します。

アイコンの印画面押すと
? まだご自分の作品として覚えていない作品の、Narou.fun のページ・カクヨムのアクセス数の画面 「ご自分の作品ですか？」とお尋ねします。「覚える」を選ぶと、以後はその作品の画面を開いたときに記録します。 どなたの作品でも開ける画面なので、ほかの方の作品は記録しません
読3 ご自分の作品の、カクヨムの作品管理・アクセス数の画面と Narou.fun のページ 開いただけで、画面の読者の反応を記録します（集計はこのページ）。 統合小説執筆環境をお使いの方向け：押すと、その画面を読み直してから、 溜まった分をまとめてクリップボードへ置き、VS Code を呼び出します（数字は溜まっている画面の数）
貼 カクヨムなどの、話の作成画面 統合小説執筆環境をお使いの方向け：統合小説執筆環境でコピーした原稿を、題と本文の欄へ入れます。 投稿ボタンはご自分で押してください

押した結果は、画面の隅に出る Chrome のお知らせで出ます （お知らせが出ないときは、Windows の「設定」→「通知」で Google Chrome の通知がオンか確かめてください）。 何もできない画面で押したときは、どの画面でなら何ができるかをお知らせします。

下の「統合小説執筆環境へ渡す」を切っている間は、? の画面と 貼 の画面（貼り込みは切っていても使えます）を除いて、 どの画面で押してもこのページの集計が開きます（読 の画面では、読み直して記録してから開きます）。 溜まっている数の印は出ません。

統合小説執筆環境と一緒に使う

統合小説執筆環境（VS Code の拡張機能）をお使いの方は入れてください。 切っている間は、アイコンを押すとこのページの集計が開きます（話の作成画面では、これまでどおり貼り込みます）。

統合小説執筆環境へ渡す分（統合小説執筆環境をお使いの方向け）

画面を開いたときに記録した読者の反応は、統合小説執筆環境へ渡すために、ここにも溜めておきます。 溜まっている分があれば、ほかの画面でアイコンを押しても、まとめて渡します（アイコンに「読3」のように件数が出ます）。 渡すと溜まりは空になりますが、上の集計の記録は消えません。 統合小説執筆環境をお使いでなければ、ここは使わなくて構いません（溜まりは上限を越えると古いものから消えます）。

この拡張がしないこと

    
    
      
  • 投稿ボタンは押しません（送信はご自分の手で）
    • 
      
  • 通信は一切しません。集計もこの拡張の中だけで計算し、外のプログラムを読み込みません。VS Code を呼び出すのは、お手元の VS Code を前に出すだけで、どこへも何も送りません（読者の反応はクリップボードで渡します）
    • 
      
  • 読者の反応を記録する場所・溜める場所は、この拡張の中の保存（Chrome の拡張用の保存場所）だけです。保存は通信ではなく、どこへも送りません
    • 
      
  • ページの中に、表示や部品を差し込みません（結果は Chrome のお知らせで出します）
    • 
      
  • 勝手に新しいタブを開きません。開くのは、入れた直後のこのページと、アイコンの右クリックで選んだときのこのページ、「統合小説執筆環境へ渡す」を切っているときにアイコンを押したときのこのページ、上の「統合小説執筆環境」のリンクを押したときだけです（リンクにデータは載せません）
    • 
      
  • ログイン画面では動きません
    • 
      
  • 本文は読みません。読むのは、ご自分の管理画面と、ご自分の作品の Narou.fun のページに出ている数だけです。ほかの方の作品は記録しません（どなたの作品でも開ける画面では、「覚える」を選んだ作品だけを記録します）
    • 
      
  • 公募の一覧のページ（ノベルポータル・ツクリテミライの3ページ）では、アイコンを押したときだけ、並んでいる公募を読んでクリップボードへ置きます。読んだ公募はこの拡張の中に残しません
    • 
      
  • なろう本体とそのアクセス解析（KASASAGI）は読みません
    • 
      
  • 開いただけでは貼り込みません。開いただけで読むのは、ご自分の作品の読者の反応の画面だけで、開いたときに1回だけです（ページを見張り続けません）
