統合小説執筆環境ヘルパー

VS Code の拡張機能「統合小説執筆環境」でコピーした原稿を、ご自分で開いた投稿画面の欄へ入れます。 ご自分の管理画面に出ている読者の反応を、統合小説執筆環境へ戻すこともできます。

使い方

ツールバーのアイコンを押すか、ページの上で右クリックして「統合小説執筆環境ヘルパー：…」を選ぶと、 いま開いている画面でできることを1つだけ実行します。

アイコンの印画面押すと
貼 カクヨムなどの、話の作成画面 統合小説執筆環境でコピーした原稿を、題と本文の欄へ入れます。投稿ボタンはご自分で押してください
読 カクヨムの作品管理・アクセス数の画面、ご自分の作品の Narou.fun のページ 画面に出ている読者の反応をコピーし、VS Code を呼び出します（統合小説執筆環境が取り込みます）

印の無い画面で押したときは、どの画面でなら何ができるかをお知らせします。 押した結果は、画面の隅に出る Chrome のお知らせで出ます （お知らせが出ないときは、Windows の「設定」→「通知」で Google Chrome の通知がオンか確かめてください）。

この拡張がしないこと

  • 投稿ボタンは押しません（送信はご自分の手で）
  • 通信は一切しません。VS Code を呼び出すのは、お手元の VS Code を前に出すだけで、どこへも何も送りません（読者の反応はクリップボードで渡します）
  • ページの中に、表示や部品を差し込みません（結果は Chrome のお知らせで出します）
  • ログイン画面では動きません
  • 本文は読みません。読むのは、ご自分の管理画面と、Narou.fun の作品ページに出ている数だけです（Narou.fun はどなたの作品のページでも開けるので、ご自分の作品のページで押してください。ほかの方の作品の数は、VS Code の拡張機能「統合小説執筆環境」が取り込みません）
  • なろう本体とそのアクセス解析（KASASAGI）は読みません
  • 開いただけでは、貼り込みも読み取りもしません。対応している画面が開いたことだけを拡張の中へ知らせて、アイコンに印を付けます
