統合小説執筆環境ヘルパー

VS Code の拡張機能「統合小説執筆環境」でコピーした原稿を、ご自分で開いた投稿画面の欄へ入れます。 ご自分の作品の読者の反応を、画面を開いたときに溜めておき、まとめて統合小説執筆環境へ渡すこともできます。

使い方

ツールバーのアイコンを押すか、ページの上で右クリックして「統合小説執筆環境ヘルパー：…」を選ぶと、 いま開いている画面でできることを1つだけ実行します。

アイコンの印画面押すと
貼 カクヨムなどの、話の作成画面 統合小説執筆環境でコピーした原稿を、題と本文の欄へ入れます。投稿ボタンはご自分で押してください
読3 ご自分の作品の、カクヨムの作品管理・アクセス数の画面と Narou.fun のページ 開いただけで、画面の読者の反応を溜めます（数字は溜まっている画面の数）。押すと、その画面を読み直してから、 溜まった分をまとめてクリップボードへ置き、VS Code を呼び出します（統合小説執筆環境が取り込みます）
? まだご自分の作品として覚えていない作品の、Narou.fun のページ・カクヨムのアクセス数の画面 「ご自分の作品ですか？」とお尋ねします。「覚える」を選ぶと、以後はその作品の画面を開いたときに溜めます。 どなたの作品でも開ける画面なので、ほかの方の作品は溜めません

溜まっている分があれば、ほかの画面で押しても、まとめて渡します（アイコンに「読3」のように件数が出ます）。 溜まりも無い画面で押したときは、どの画面でなら何ができるかをお知らせします。 押した結果は、画面の隅に出る Chrome のお知らせで出ます （お知らせが出ないときは、Windows の「設定」→「通知」で Google Chrome の通知がオンか確かめてください）。

この拡張がしないこと

    
    
      
  • 投稿ボタンは押しません（送信はご自分の手で）
    • 
      
  • 通信は一切しません。VS Code を呼び出すのは、お手元の VS Code を前に出すだけで、どこへも何も送りません（読者の反応はクリップボードで渡します）
    • 
      
  • 読者の反応を溜める場所は、この拡張の中の保存（Chrome の拡張用の保存場所）だけです。保存は通信ではなく、どこへも送りません
    • 
      
  • ページの中に、表示や部品を差し込みません（結果は Chrome のお知らせで出します）
    • 
      
  • ログイン画面では動きません
    • 
      
  • 本文は読みません。読むのは、ご自分の管理画面と、ご自分の作品の Narou.fun のページに出ている数だけです。ほかの方の作品は溜めません（どなたの作品でも開ける画面では、「覚える」を選んだ作品だけを溜めます）
    • 
      
  • なろう本体とそのアクセス解析（KASASAGI）は読みません
    • 
      
  • 開いただけでは貼り込みません。開いただけで読むのは、ご自分の作品の読者の反応の画面だけで、開いたときに1回だけです（ページを見張り続けません）
