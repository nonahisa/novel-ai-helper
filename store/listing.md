## 詳しい説明（ここから下を「説明」の欄へそのまま貼る）

```
小説を書く方のための拡張機能です（いまはテスト中です）。ご自分の作品の読者の反応を、管理画面を開いたときに記録し、作品ごとに簡単に集計します。

■ できること
・ご自分の作品の読者の反応（PV・ブックマーク・評価・応援など）を、管理画面を開いたときにこの拡張の中へ記録します
・作品ごとに、いまの数・日ごとの推移（14日ぶん）・離脱率・ブックマーク率・評価率を、この拡張の説明のページで集計します。率が出せないときは 0% とせず、足りない材料を書きます
・作品のタグと、連載中か完結かも読み、集計の見出しの下に出します
・対応している画面
　- カクヨム：作品管理の画面、アクセス数の画面
　- アルファポリス：マイページの作品管理の一覧、作品の管理画面、作品の設定の画面（設定の画面は読むだけで、欄は書き換えません）
　- 小説家になろうの作品：分析サイト「なろうファンDB」の作品のページ
・同じ作品の同じ日の分は1つにまとめます（開き直しても増えません）。残すのは 20作品・180日までで、越えたら古いものから消えます
・取得できる画面を初めて開いたとき、「開いたときに自動で取得しますか？」とお尋ねします（画面の種類ごとに1回だけ）。「自動で取得する」と答えた種類の画面は、開いたときに記録して、ツールバーのアイコンの吹き出しで「取得しました」とお知らせします。答えは説明のページで後から変えられます

■ 使い方（3つの手順）
1. ご自分の作品の管理画面を開く
　カクヨムなら、ログインして「作品の管理」から作品を選んだ画面。アルファポリスなら、マイページの作品管理の一覧か、作品の管理画面。小説家になろうの作品なら、なろうファンDB の作品のページ（db.narou.fun/novels/Nコード）です。
2. 作品を覚える
　カクヨムの作品管理の画面とアルファポリスのマイページはご本人しか開けないので、読めたら自動で覚えます。どなたの作品でも開ける画面（なろうファンDB・カクヨムのアクセス数）では、ツールバーのアイコンに「?」が付きます。アイコンを押して「覚える」を選ぶか、説明のページに Nコード・作品IDを書いて保存してください。覚えた作品だけを記録します。
3. 集計を見る
　覚えた作品の画面を開くたびに、その日の数を記録します。ツールバーのアイコンを右クリックして「集計を表示」を選ぶと、集計が開きます。

入れた直後に、この手順を書いた説明のページが1回だけ開きます。アイコンが見当たらないときは、ツールバーのパズルのかけらの印から固定してください。

■ VS Code の拡張機能「統合小説執筆環境」と一緒に使う
グラフ・作品の事情を踏まえたAIの助言・原稿との突き合わせなど、詳しい分析は VS Code の拡張機能「統合小説執筆環境」でできます。一緒に使うと、次のこともできます。受け渡しはクリップボードで行います。
・記録した読者の反応（タグ・連載の状態を含む）をまとめて渡す
・統合小説執筆環境でコピーした原稿を、カクヨム・アルファポリスの話の作成画面の題と本文の欄へ入れる。アルファポリスでは、渡された章の名前と同じ章を章の欄で選びます（投稿ボタンはご自分で押してください）
・公募（文学賞・コンテスト）の一覧のページ（ノベルポータル・ツクリテミライ）で押すと、並んでいる公募の名前・締切・字数などをまとめて渡す（統合小説執筆環境で応募先に選べます）
・カクヨムの作品管理の画面で右クリックして「章立てを取得」を選ぶと、大見出しと話の並びを渡す
説明のページの「統合小説執筆環境へ渡す」を入れると、渡すときに VS Code を前に出します（新しく入れたときは切ってあります。切っている間は、読者の反応を渡す代わりに集計が開き、公募と章立てはクリップボードへ置くだけです）。話の作成画面での貼り込みは、切っていても使えます。

■ この拡張がしないこと
・通信は一切しません。記録も集計もこの拡張の中だけで行い、外のプログラムを読み込みません
・記録する場所は、Chrome の拡張用の保存場所（この拡張の中）だけです。Google アカウントの同期も使いません
・ほかの方の作品は記録しません。どなたの作品でも開ける画面では、「覚える」を選んだ作品だけを記録します
・本文は読みません。読むのは、ご自分の管理画面（カクヨム・アルファポリス）と、ご自分の作品のなろうファンDB のページに出ている数と、集計の見出しに出す作品名・タグ・連載の状態だけです
・なろう本体とそのアクセス解析（KASASAGI）は読みません
・投稿ボタンは押しません。送信はご自分の手で行ってください
・ログイン画面では動きません。パスワードや Cookie には触れません
・ページの中に表示や部品を差し込みません。押した結果は Chrome のお知らせで出します
・開いただけでは貼り込みません。開いたときに読むのは、承認した種類の画面だけで、1回だけです（承認は設定で取り消せます）
・勝手に新しいタブを開きません

■ 記録を消すには
説明のページの「集計の記録を消す」で全部消せます。覚えた作品から外した作品は、その作品の記録も消えます。拡張機能を削除すると、保存していたものはすべて消えます。

```
