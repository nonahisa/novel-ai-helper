Chrome ウェブストアのデベロッパー ダッシュボード「ストアの掲載情報」へ貼る文です。
**名前と概要は manifest.json から自動で入ります**（ダッシュボードでは直せません。直すときは manifest.json を直して版を上げる）。

- 言語：日本語

## 名前（manifest.json の `name`）

```
統合小説執筆環境ヘルパー
```

## 概要（manifest.json の `description`。132字以内——いまは119字）

```
ご自分の作品の読者の反応（PV・ブックマーク・評価）を管理画面を開いたときに記録し、作品ごとに推移や離脱率を簡単に集計します。VS Code の「統合小説執筆環境」と一緒に使えば、原稿を投稿画面の欄へ入れることもできます。通信はしません。
```

## 詳しい説明（ここから下を「説明」の欄へそのまま貼る）

```
小説を書く方のための拡張機能です。ご自分の作品の読者の反応を、管理画面を開いたときに記録し、作品ごとに簡単に集計します。

■ できること
・ご自分の作品の読者の反応（PV・ブックマーク・評価・応援など）を、管理画面を開いたときにこの拡張の中へ記録します
・作品ごとに、いまの数・日ごとの推移（14日ぶん）・離脱率・ブックマーク率・評価率を、この拡張の説明のページで集計します。率が出せないときは 0% とせず、足りない材料を書きます
・対応している画面
　- カクヨム：作品管理の画面、アクセス数の画面
　- 小説家になろうの作品：分析サイト Narou.fun の作品のページ
・同じ作品の同じ日の分は1つにまとめます（開き直しても増えません）。残すのは 20作品・180日までで、越えたら古いものから消えます

■ 使い方（3つの手順）
1. ご自分の作品の管理画面を開く
　カクヨムなら、ログインして「作品の管理」から作品を選んだ画面。小説家になろうの作品なら、Narou.fun の作品のページ（db.narou.fun/works/Nコード）です。
2. 作品を覚える
　カクヨムの作品管理の画面はご本人しか開けないので、開いただけで自動で覚えます。どなたの作品でも開ける画面（Narou.fun・カクヨムのアクセス数）では、ツールバーのアイコンに「?」が付きます。アイコンを押して「覚える」を選ぶか、説明のページに Nコード・作品IDを書いて保存してください。覚えた作品だけを記録します。
3. 集計を見る
　覚えた作品の画面を開くたびに、その日の数を記録します。ツールバーのアイコンを右クリックして「読者の反応の集計を見る」を選ぶと、集計が開きます。

入れた直後に、この手順を書いた説明のページが1回だけ開きます。アイコンが見当たらないときは、ツールバーのパズルのかけらの印から固定してください。

■ VS Code の拡張機能「統合小説執筆環境」と一緒に使う
グラフ・作品の事情を踏まえたAIの助言・原稿との突き合わせなど、詳しい分析は VS Code の拡張機能「統合小説執筆環境」でできます。説明のページの「統合小説執筆環境へ渡す」を入れると、次のことにも使えます（新しく入れたときは切ってあります）。
・記録した読者の反応をまとめてクリップボードへ置き、VS Code を前に出す（統合小説執筆環境が取り込みます）
・統合小説執筆環境でコピーした原稿を、カクヨムの話の作成画面の題と本文の欄へ入れる（投稿ボタンはご自分で押してください。アルファポリスの話の作成画面は試験中です）
「統合小説執筆環境へ渡す」を切っていても、話の作成画面での貼り込みは使えます。

■ この拡張がしないこと
・通信は一切しません。記録も集計もこの拡張の中だけで行い、外のプログラムを読み込みません
・記録する場所は、Chrome の拡張用の保存場所（この拡張の中）だけです。Google アカウントの同期も使いません
・ほかの方の作品は記録しません。どなたの作品でも開ける画面では、「覚える」を選んだ作品だけを記録します
・本文は読みません。読むのは、ご自分の管理画面と、ご自分の作品の Narou.fun のページに出ている数だけです
・なろう本体とそのアクセス解析（KASASAGI）は読みません
・投稿ボタンは押しません。送信はご自分の手で行ってください
・ログイン画面では動きません。パスワードや Cookie には触れません
・ページの中に表示や部品を差し込みません。押した結果は Chrome のお知らせで出します
・開いただけでは貼り込みません。開いただけで読むのは、ご自分の作品の読者の反応の画面だけで、開いたときに1回だけです
・勝手に新しいタブを開きません

■ 記録を消すには
説明のページの「集計の記録を消す」で全部消せます。覚えた作品から外した作品は、その作品の記録も消えます。拡張機能を削除すると、保存していたものはすべて消えます。

■ お問い合わせ
GitHub の Issues へお寄せください：https://github.com/nonahisa/novel-ai-helper/issues
```

## 補足（貼らない。書いた中身の裏付け）

| 書いたこと | 裏付け |
|---|---|
| 記録する指標（PV・ブックマーク・評価・応援など） | `content/statsSites.js` の `metric`（pv・bookmarks・points・reviews・likes・comments・narou_ratingPoints・narou_raters・narou_weeklyReaders） |
| 推移14日ぶん・3つの率・0% としない | `common/history.js`（`TREND_DAYS = 14`、率の式、材料が欠けたら理由を返す） |
| 20作品・180日 | `common/history.js` の `HISTORY_LIMITS`（ほかに月ごと24か月・150万字） |
| カクヨムの作品管理は開いただけで覚える／他は「?」から | `content/statsSites.js` の `ownerOnly`、`common/stash.js` の `stashDecision` |
| 入れた直後に説明のページが1回だけ開く | `background.js` の `onInstalled`（`details.reason === "install"`） |
| 新しく入れたときは「渡す」が切ってある／切っていても貼り込める | `common/settings.js`、`background.js` の `実行する`（0.11.1） |
| アルファポリスの貼り込みは試験中 | `content/sites.js`（欄の指定が推測のまま・作品IDの照合なし） |
| 通信しない・投稿ボタンを押さない・ページへ差し込まない・新しいタブを開かない | `test/redLine.test.js` がソースを走査して見張る |
| 拡張を削除すると保存が消える | `chrome.storage.local` は拡張を削除すると Chrome が消す（`common/settings.js` の注記にも同じ前提がある） |
